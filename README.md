# 看拼音写词语 · 七年级上册田字格生成器

统编七年级语文上册「看拼音写词语」练习纸生成器。

- 第 1–3 课按课文词语
- 其余课按《读读写写》分课
- 可单课或多课勾选
- 拼音引擎（pinyin-pro 3.26.0）已内置，**无需联网**
- 支持练习页 / 答案页、多音字手改、打印成 PDF

## 使用

下载 [看拼音写词语.html](./看拼音写词语.html)（或本仓库的 `index.html`），用 Chrome / Edge 直接打开。

打印时选择 A4，边距「无」，勾选「背景图形」以保留田字格虚线。

## 许可

页面代码可自由使用。拼音转换使用 [pinyin-pro](https://github.com/zh-lx/pinyin-pro)（MIT）。
